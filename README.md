# lld-builds

Low-level design (LLD) practice problems implemented in Java.

## Problems

| Problem | Pattern | Status |
|---------|---------|--------|
| Parking Lot | OOP, Strategy | In progress |
| Vending Machine | State Machine | In progress |
| Splitwise | Graph, Debt simplification | In progress |
| LRU Cache | LinkedHashMap / Doubly-LL + HashMap | In progress |
| LFU Cache | Min-heap + HashMap | In progress |
| Rate Limiter | Token Bucket / Sliding Window | In progress |
| Configuration Management Platform | Observer, Versioning | In progress |

## Goals

- Practice class design, SOLID principles, and design patterns
- Prepare for system design / LLD interview rounds
- Clean, testable Java code with no frameworks (pure JDK)

Work in progress — problems added incrementally.
